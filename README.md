# 50/30/20 Inflation & Budget Matrix Engine

A highly responsive, browser-native budgeting platform designed to recalculate traditional personal finance frameworks under active cost-of-living inflation pressures. 

## 🚀 Architectural & Core Features
- **Dynamic Cost-of-Living Adjustment**: Incorporates a live range-slider tracking up to a 40% local overhead inflation increase, calculating its exact impact on discretionary income.
- **Automated Financial Splitting**: Instantly processes net monthly revenue into segmented variables matching the classic 50/30/20 financial rule (Needs, Wants, Savings).
- **Zero-Dependency Architecture**: Crafted entirely as a standalone code ecosystem with integrated, performance-optimized CSS wrappers to maintain rapid load execution across mobile structures.
- **Dual-Layer Script Delivery**: Built-in visual background container modules are pre-aligned to manage script layers safely without introducing cumulative layout shifts.

## 🛠️ Usage & Deployment Execution
To host this utility or run it as a standalone localized window, drag the `index.html` markup layer into any standard desktop or mobile web browser. For public access, position the file folder path under `/inflation-budget-tool/` within a verified GitHub Pages hosting directory.
